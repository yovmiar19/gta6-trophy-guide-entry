Leonida Ledger — an offline guide and tracker for all 55 GTA 6 PS5 trophies, with a three-stage roadmap to platinum, missable flags, story-spoiler hiding, and a checklist saved in localStorage (export/import included). Every trophy's guide is written in the author's own words and cites its sources.

## Run it

```sh
python3 -m http.server --directory app
```

Then open http://localhost:8000/ in a browser. No build step, no network — the guide is plain static files.
